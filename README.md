# Student Depression Prediction System

## Overview

This project presents a Student Depression Prediction System developed to analyse student-related data and estimate the likelihood of depression. The system is designed to support early awareness by identifying patterns that may indicate mental health risks. It combines machine learning techniques with a simple web interface so that users can easily interact with the model and obtain predictions.

## Features

The application allows users to enter relevant details and receive a prediction instantly. It integrates two different machine learning approaches, providing both a simple baseline and a more advanced predictive model. The interface is designed to be clear and easy to use, ensuring that even non-technical users can operate the system without difficulty.

## Technologies Used

The system is built using Python. Data processing is carried out with libraries such as Pandas and NumPy, while Scikit-learn is used to develop and train the machine learning models. The user interface is created using Streamlit, which enables quick deployment of a web-based application.

## Project Structure

The project is organised into separate components to maintain clarity and modularity. The dataset is stored in a dedicated folder, while preprocessing scripts handle data cleaning and preparation. Model files contain the implementation and training of Logistic Regression and Random Forest algorithms. The main application file connects user inputs with the trained models and displays the results through the interface.

## Installation

To run the project, first ensure that Python is installed. Download or clone the project files, then install the required dependencies using the command `pip install -r requirements.txt`. After installation, open a terminal in the project directory and run `streamlit run app.py` to start the application.

## Usage

Once the application is running, users can input the required information into the provided fields. After submitting the data, the system processes the input and generates a prediction indicating the likelihood of depression. The result is displayed immediately on the screen.

## Model Information

Two models are used in this project: Logistic Regression and Random Forest. Logistic Regression provides a straightforward and interpretable approach, while Random Forest improves prediction by capturing more complex relationships in the data. The models are trained and evaluated using standard performance measures to ensure reliable results.

## Future Enhancements

The system can be improved by introducing more advanced algorithms and increasing the size and diversity of the dataset. Deploying the application on cloud platforms and enabling real-time data integration would make it more scalable and practical for wider use. Collaboration with domain experts could also help refine the system and improve its effectiveness.

## Ethical Considerations

This project deals with sensitive information related to mental health. Therefore, it is important to handle data responsibly and ensure user privacy. The predictions generated by the system are not a substitute for professional advice and should only be used as a supportive tool.
